# Write a Blog Post

Posts live at `src/content/blog/{locale}/slug.md` (Markdown only — MDX is not installed) — one file per locale. The slug becomes the URL.

Required frontmatter (schema in `src/content.config.ts`):

```yaml
---
title: "Post Title"
description: "A brief description"        # used for meta description + OG
author: "Author Name"
publishedDate: 2026-01-15
---
```

Optional: `tags` (array, defaults to `[]`), `updatedDate`, `draft: true` (hides from listings while writing), `ogImage` (path to a custom OG image in `public/og/` — otherwise one is auto-generated by Satori from the title/description).

- For multilingual sites, create the post in every locale directory or the post only exists in one language.
- Verify: `pnpm build` — the post route and its OG image (`dist/og/{locale}/{slug}`) should appear in the output.
